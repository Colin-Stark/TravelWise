# Prompt for TravelWise Project Work Breakdown Structure

## 🎯 Original Prompt
> As the project manager expert you are, create a Work Breakdown Structure for the TravelWise app we have been working on. It needs to have all detailed phases from the development to the deployment phase.

## ❓ Format Clarification
> What is the best structure/format for my WBS? I'm hesitating if I do it as a chart/graphic or just an Excel/Word version. I need it to be detailed and easy to understand.

## 📤 Generated Output
The above prompt was used to generate the structured WBS for the **TravelWise App**, including:
- Development Phase
- Testing & Debugging
- Deployment
The Initiation and Planning, and Design Phase were not included because they have already been done during this semester and will not account for the semester ahead.

The WBS was delivered in:
- ✅ Markdown tree format (for GitHub)
- ✅ Visual diagram (Lucidchart style reference)
